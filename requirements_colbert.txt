# Isolated environment for the ColBERT-style external-baseline scripts
# (scripts/eval_colbert_baseline.py, colbert_retrieve_context.py,
# colbert_generate_and_score.py, mcnemar_adaptive_vs_colbert.py).
#
# This is DELIBERATELY a separate venv (.venv_colbert/, gitignored), not
# an addition to the main requirements.txt: pylate hard-pins
# sentence-transformers==5.3.0 and transformers<=5.3.0, which conflicts
# with the main project's pins (sentence-transformers==5.6.1,
# transformers==5.14.1, used for embedding fine-tuning/reranking).
# Installing pylate into the main .venv once already silently downgraded
# both plus torch (to a CPU-only build) via pip's dependency resolution --
# see CLAUDE.md.md, 2026-08-01, "real external SOTA baseline" entry --
# hence the isolation.
#
# Build with:
#   python -m venv .venv_colbert
#   .venv_colbert/Scripts/pip install --index-url https://download.pytorch.org/whl/cu121 \
#       --extra-index-url https://pypi.org/simple torch==2.5.1+cu121
#   .venv_colbert/Scripts/pip install pylate chromadb==1.5.9 rank-bm25==0.2.2 nltk==3.10.0 pandas numpy
#   .venv_colbert/Scripts/pip install --no-deps --index-url https://download.pytorch.org/whl/cu121 \
#       --extra-index-url https://pypi.org/simple torch==2.5.1+cu121
#     # (pylate's own resolution re-downgrades torch to CPU-only; the final
#     # --no-deps reinstall restores CUDA without disturbing pylate's other
#     # pinned deps -- see the same CLAUDE.md.md entry for why this two-step
#     # order is necessary.)
